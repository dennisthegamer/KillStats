# KillStats

**Track every kill, estimate your loot, and dominate the battlefield!**

KillStats is a lightweight, client-side Fabric mod that tracks your entity kills during each play session and shows live statistics in a configurable in-game HUD overlay.

## Features

- **Per-mob kill tracking** - see exactly how many of each mob type you've defeated
- **Estimated drop value** in Emeralds, with Looting enchantment support
- **40+ mob types** covered, including bosses
- **Full & compact HUD modes** with configurable position, opacity, and scale
- **Session timer** with start/pause/resume and auto-pause when menus are open
- **Session summary** in chat on world exit or reset, with optional persistent sessions
- **Milestone notifications** for total and per-mob kills
- **Boss kill flash effects** and sound alerts
- **Client-side only** - no server installation required

## Requirements

- **Minecraft**: 26.2
- **Fabric Loader**: 0.19.2 or higher
- **Fabric API**: Required
- **Java**: 25 or higher
- **ModMenu** + **YACL**: Optional (for the in-game config screen)

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/)
2. Download [Fabric API](https://modrinth.com/mod/fabric-api)
3. Download KillStats and place both JARs in your `mods` folder
4. Launch Minecraft
